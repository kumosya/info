# libc 的兼容实现

源码位于 `lib/libc/fallback/`，声明仍使用 `include/stdc/` 和 `include/posix/` 中对应的标准头文件，不另设应用接口。

同一类标准接口放在对应头文件命名的 C 源文件中。函数先检查参数，再使用已有的文件、任务、内存或同步后端完成操作；不具备后端的接口按标准约定设置 `errno` 并返回失败，不能用空实现表示操作成功。

`lib/libc/` 中已有实际运行时实现的函数由对应实现负责，例如文件描述符由 `fd.c` 管理，映射由 `mman.c` 管理，进程由 `task_runtime.c` 管理。fallback 不再定义这些函数的第二份实现。
