## B01：nice 与资源限制

PID 和 TID 统一使用单调递增的编号空间，主线程 TID 等于 PID；fork 继承调用线程 nice，新线程继承创建线程 nice，exec 保留 nice。原子相对调整和绝对调整都在内核运行队列锁下执行，先按旧 weight 结算运行时间，保留 vruntime，触发目标 CPU 重调度。普通用户的提升权限由目标进程 RLIMIT_NICE 检查，root 提供当前系统的调度及资源管理特权。

资源表按 Task 共享。RLIMIT_NICE 默认软硬值均为 0，RLIMIT_CORE 保持 v0.1.3 语义；其他资源尚无执行点时返回 ENOTSUP，不假报生效。prlimit 在同一把进程锁下取得旧值并可选提交新值。参数/输出指针预检失败不提交限制修改。
