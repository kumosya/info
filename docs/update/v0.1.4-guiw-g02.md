日期：2026-10-24。GUI 包版本 0.4.0，线协议 4。

## 本批实现

- libosgui 增加声明式公共头文件 geometry.h、image.h、widgets.h；PNG 加载、缩放、预算及缓存，裁剪、透明图像、圆角渐变、阴影，统一持续控件。
- 服务端增加分块纹理上传、窗口资源归属和预算，以及窗口级鼠标捕获。修正焦点 gained/lost 事件和输入 union 混读，避免鼠标位移污染修饰键。
- calc、taskmgr、editor 迁移到 Ui/Button。按下显示压入效果，释放执行，拖出取消，失焦/捕获丢失取消动作；悬停只更新控件脏区。保留任务管理器现有线程视图、nice 调整、进程身份校验及编辑器异步文件处理。
- editor 的测宽改用 Font::measure，避免定位光标时创建整张文本位图；正文仍支持 Tab，F6 进入工具栏导航。
- 自有 GUI 公共头文件保持仅声明，不新增 inline 实现或 inline constexpr 公共变量。

## console 启动界面

启动显示由 console 负责，沿用内核专用 graphic 字体库，不引入 GUI 依赖。启动缓冲与六个文本 TTY 分开，启动期间的 TTY 输出仍写入各自缓冲，键盘不进入隐藏登录界面，快捷键和 Switch 请求均不能切换 TTY。

TerminalRequest 末尾追加 BootStatus、BootComplete、GetBootState，保留已有操作值；OS 运行库增加 BootConsole，使用显式 endpoint 和有限 IPC 截止时间。只有 managedService 且 serviceRole=Init 的调用者可以提交结果或完成启动。名字限制为有终止符的可打印 ASCII，拒绝转义序列、错误长度、附带句柄及越界 TTY。

init 的 Lifecycle 观察器记录启动结果；console 就绪前保存有界日志，就绪后补显 `[ OK ] Started xxx.` / `[FAILED] Failed to start xxx.`。补采 task/device 所管理服务的状态，并记录各 TTY 会话结果。观察器在后台监督阶段只修改日志，不在回调中执行 console IPC。

SessionSupervisor 不再提前切换图形 TTY。会话启动结束后，init 按 console 配置的 defaultTerminal 选择可用目标，发送 BootComplete。console 确认图形显示交接成功后才结束启动状态、开放 TTY 切换并呈现目标；没有可用会话时继续保留启动界面。首选图形终端交接失败可回退到可用文本 TTY。

console 重启时先停用 guiw 显示，再重建启动屏；init 根据服务 endpoint 实例身份重放最新结果并重新交接。完成回执丢失时查询实际启动状态，避免无限重试已完成交接。

console 是依赖 fs/users/tty 的磁盘服务，因此它上线前的结果只能在上线后补显；更早的故障诊断仍使用已有串口日志。

- QEMU 分别运行 taskmgr 和 editor，截图对比确认 Sort/Find 按住时外观改变、业务状态不变，释放后才切换排序/打开查找栏。

PNG 首版仅 8 bit 非交错，TTF 延续随包校验字体及既有字符覆盖；完整图片指针、登录、锁屏、桌面、文件选择器、Settings 等仍属于后续 G03–G12。

职责上分离资源解码、像素绘制、控件交互、服务启动状态和显示交接，避免应用复制按键状态机；使用已有 TTY 渲染和 IPC 机制完成启动屏，不引入额外启动显示服务。
