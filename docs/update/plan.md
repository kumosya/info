# 开发计划

## v0.1-beta


- 0.1.5
  - 统一 storage 块设备接口，迁移启动内存镜像与 VirtIO Block。
  - 明确设备能力、逻辑块大小、容量与最大传输限制，补齐分区边界和整数溢出校验。
  - 统一缓存刷新、错误与超时语义，保证迟到完成、设备停止和 DMA 资源回收安全。
  - 加入必要的请求、字节、错误及超时计数，完成现有启动路径、文件系统和 SDK 回归。

- 0.1.6
  - 支持 AHCI 硬盘驱动与 ATA
  - storage服务建立块 I/O 请求队列，实现I/O Merging、批量异步提交、根据设备（SCSI 和 VirtIO等）选择策略。

- 0.1.7
  - 内存管理补齐 msync 的同步语义，完成匿名共享映射、文件共享映射、基本脏页跟踪和 MAP_FIXED。

- 0.1.8
  - 完善浮点处理机制

## v0.2-beta

- 0.2.0
  - 实现 ACPI 电源管理，并提供关机、重启电源服务，先不提供安全关机、重启功能。

- 0.2.1
  - 完成 ext4 日志重放和崩溃恢复功能，以及更多磁盘布局的安全写入。
  
- 0.2.2
  - 完成ext3的 JBD 日志事务及恢复。

- 0.2.3
  - 实现fsck服务，为离线检查/修复工具，由启动流程协调。

- 0.2.4
  - 实现I/O 性能计数器。

- 0.2.5
  - 实现批量扇区读写、请求合并。

- 0.2.6
  - 完善fat文件系统，fat32改成fat，同时增加对fat12和fat16文件系统的支持

- 0.2.7
  - 将tmpfs、procfs、sysfs、devtmpfs作为正式的文件系统，与ext3 fat exfat平级。

- 0.2.8
  - 实现SquashFS

- 0.2.9
  - 加入软盘驱动

- 0.2.9
  - 实现初步的 NVMe 支持，包括控制器初始化、命名空间识别、块读写、缓存刷新与错误恢复。

- 0.2.10
  - 实现 NTFS 的读功能，暂不支持写

- 0.2.11
  - 实现 virtio-scsi 与 SCSI 块设备

# v0.3-beta

- 0.3.1
  - 完善权限隔离

- 0.3.2
  - 实现安全关机与重启

- 0.3.3
  - 实现电源中的睡眠功能
