# v0.1.4：guiw G03 图形登录与独立登录界面模块

日期：2026-10-24。GUI 包统一为 0.5.0，线协议 5；OSInfo 计划版本仍为 v0.1.4。

## 实现与边界

init 改为启动 `/usr/bin/guiw-session`，等待登录界面绘制并向窗口服务确认就绪后，再由 console 完成启动交接。`/etc/sessions` 新增 `graphical` 项；保留 terminal 配置供用户主动启动的终端程序使用，tty1–tty6 继续运行原文本登录。旧配置缺少 graphical 时保留文本登录，不回退为自动打开 GUI terminal。

移除 guiw 的 Welcome/System status 演示窗口及其输入、绘制分支。登录前不创建用户桌面或 terminal。窗口服务的 Starting/Greeter/Authenticating/Desktop 状态独立于 TTY 显示开关；只有 init 可以通过 PID、启动时间和父子关系绑定会话宿主。

`guiw-session` 是独立的普通进程，不具有 guiw 合成服务身份。它在独立 POSIX 会话中调用 users 新增的 GraphicalLogin，users 验证密码并通过内核建立调用进程的 UID/GID/补充组和认证会话。合成服务只获得读取认证会话标签的能力，建立身份仍仅允许持有 users 能力的服务执行。

登录宿主在工作线程中执行账号枚举和认证，UI 线程只处理输入和状态。每次提交携带宿主请求代次；取消后迟到的认证结果不能启动桌面，宿主结束该次会话，由 init 清理并重建登录入口。失败采用有上限的重试退避。密码输入、IPC 副本和工作缓冲显式擦除，登录宿主禁用 core dump，不走 AutoLogin。

认证成功后，宿主再次核对内核认证标签和真实/有效 UID、GID，再设置 HOME、USER、LOGNAME、SHELL、PATH、XDG_RUNTIME_DIR、XDG_SESSION_TYPE 及工作目录，通过 posix_spawn 将环境传给用户桌面。桌面就绪后窗口服务才隐藏登录界面并呈现用户窗口；无法建立身份、设置环境或启动桌面时，保留登录遮罩并回退。

基础 `/usr/bin/guiw-desktop` 提供 terminal/calc/taskmgr/editor 的手动启动入口，以登录用户身份运行。它只是后续桌面外壳的基础；壁纸、Dock、顶部栏、通知、设置和正式锁屏/注销属于 G04–G12。

## 动态库与 ABI

登录界面位于 `/usr/lib/guiw/libguiw-login.so`，C ABI v1 头文件为 `guiw/login-api.h`。函数表校验版本和结构长度，覆盖创建、销毁、事件、绘制、状态及账号列表；认证结论始终来自宿主和 users 服务。仅加载 root 所有、不可被组/其他用户写入的固定系统路径。

模块可独立构建，并提供 `/usr/bin/guiw-login-preview` 预览宿主；预览不会执行认证。模块、真实宿主、基础桌面和预览随 guiw.inpk 打包，最终发行产物仍是库包、guiw 包及应用 ZIP。

补齐 libc 的 dlopen/dlsym/dlclose/dlerror，将运行期操作交给现有解释器的 ELF 校验、映射、依赖解析、重定位、W^X、RELRO 及构造/析构机制，不另写一套 GUI 专用 ELF 装载器。错误装载回滚临时映射与缓冲；支持本地/全局作用域、句柄引用和每线程错误。解释器后续读取模块时使用共享运行库分配器，避免两份运行库堆状态重叠。

当前 RTLD_LAZY 也立即绑定；dlclose 释放逻辑引用，模块保持驻留至进程结束，再逆序执行析构。暂不支持 TLS/IFUNC、符号版本、递归 dlopen 及已有解释器不支持的 ELF 重定位格式。这些限制不影响本批实际模块。

## 显示与输入边界

登录阶段只呈现可信宿主窗口；桌面阶段只呈现对应内核认证用户及会话的窗口。PTY 内的 shell 可以创建独立 POSIX 会话，窗口服务在核对真实认证 UID 和宿主进程祖先关系后保留它的图形会话归属；其他 TTY 的同 UID 进程不因此自动获得该桌面的窗口或剪贴板。

未认证程序不能创建登录遮罩、置顶抢焦点或读取图形剪贴板。原始 input 服务订阅/读取限制为受管理的 console/window 服务，普通应用经窗口事件通道接收属于自身的输入。控制器死亡或重启后清除显示授权、捕获、焦点和剪贴板，不能展示旧的认证桌面。

可信全屏表面受显示尺寸限制，普通窗口保留 704×448 限制；服务端像素存储统一限制 96 MiB，COW 分离也计入预算。库的裁剪和批次验证配套支持全屏尺寸，纯鼠标移动仍只更新局部区域。

显示交接增加实际状态查询：繁忙或回执丢失时，console 确认 guiw 的可见状态后才提交自身 TTY 状态。窗口服务拒绝已经取消的交接请求，避免短超时后出现一方已切换、另一方未切换。console 启动完成等待范围也相应覆盖该交接。

## 验证

- 目标平台内核、服务、libc、OS 运行库和四个 0.5.0 GUI 包构建成功；登录模块及预览程序独立构建成功。
- ASan/UBSan：原有客户端生命周期、图像资源/控件，以及新增登录 ABI、密码、提交、重试焦点、取消、会话绑定、全屏预算和 COW 测试。
- QEMU：显式登录、错误密码拒绝、正确凭据进入桌面、无自动 terminal、tty1/tty7 切换；非 root 用户实际 UID/GID 1000、两项补充组、HOME=/home/alice。
- 最终配套镜像：从真实软件包目录安装四个 0.5.0 GUI 包，完成登录、桌面按钮启动 Calculator、tty1/tty7 往返切换；串口确认实际显示交接。console 宿主回归覆盖切换成功但回执丢失后的状态确认。
- QEMU：dlopen 错误文件连续回滚、本地/全局符号、构造/析构、无效句柄及 dlerror。
- QEMU 故障注入：模块缺失、损坏 ELF、ABI 不兼容、模块崩溃、取消认证、认证端点消失、返回 profile 但没有内核认证身份、桌面程序缺失，均不能进入未认证桌面。

详细串口日志和截图保存在 `info/build/g03-login-smoke-*`、`info/build/g03-fault-*` 下。最终镜像验收目录为 `info/build/g03-login-smoke-4f86ff8a/`，交付文件为 `guiw/build/release/osinfo-v0.1.4-g03.img`（160 MiB）。该镜像使用开发账号配置，root 空密码，但必须手动提交登录；非 root 测试账号和故障注入程序仅存在于各自的隔离测试镜像中。

四个 0.5.0 GUI 包已导入 OSInfo 软件包目录；发行 SDK 同时包含 `include/guiw/login-api.h`。登录模块、会话宿主和桌面外壳分别承担显示、认证协调与应用启动职责，复用既有 ELF 加载和 users 认证后端。项目原有运行镜像、G02 镜像与调试配置保留；下一批为 G04 锁屏、恢复及注销。
