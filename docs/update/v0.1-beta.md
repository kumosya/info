# v0.1-beta 更新日志

## v0.1.1

- 加入/proc目录显示进程状态的功能。
- 修复了每个 tty 所运行的 sh 不会因为执行了 `killall sh` 而全体瘫痪的 bug。

## v0.1.2

- TTY 首次、logout、异常退出后都经 login 启动。GUI 新终端也使用同一入口。
- users 新增 AutoLogin 即自动登录，要求唯一空密码 root，并且会校验调用者 root 身份与控制终端。
- IMG/ISO 默认 development profile，提供唯一空密码 root；普通 make install 不执行该 profile。可加入参数 `EXPORT_ACCOUNT_PROFILE=system` 导出普通账户模板。
- 完善了 DMA 模块，DMA API 必须持有设备资源域，MMIO 只允许已 claim 的设备，BAR 范围在 DMA 开启前探测并缓存。DMA 页使用外部映射，物理引用归资源域；正常 close 不会将仍可能被设备访问的页交回物理分配器。
- 新增 task、mm 等服务的故障恢复机制。

## v0.1.3

- 增加程序崩溃之后进行 core dump 的机制
- 重新整理了一下头文件和 os c++ 库

## v0.1.4

- 动态链接器优化，提高打开软件的速度
- 支持时区切换

## v0.1.5

- 统一 BootImage 与 VirtIO Block 接口，增加按父设备统计的完成请求。
- 修正 SDK 应用链接时 ELF note 被误纳入解释器段的问题。
- 启动时仅修正与预期不符的用户目录权限和属主，减少重复的 inode 写入与设备同步。

## v0.1.6

- 支持 AHCI SATA 硬盘和 IDE ATA PIO 硬盘，读取 ATA IDENTIFY 信息，支持 LBA28/LBA48 寻址和设备缓存刷新。
- 文件访问按属主、主组、附加组及其他用户权限检查；补齐 access 的身份检查和 sticky 目录中重命名覆盖目标的权限检查。
- 修正动态链接器对运行环境实例函数的调用，保留 exec 前的终端编号、环境变量、工作目录和标准输入输出；tty1–tty6 分别运行自己的登录会话。
- 文字终端 Ctrl+L 清除历史显示后重绘提示符和当前输入，保留编辑位置。
- 显存使用各 CPU 一致的写合并类型，内核与用户显存映射使用相同缓存属性。
- PS/2 输入通过中断唤醒并定期检查控制器缓冲区，读取初始化或调度延迟期间积存的数据。
