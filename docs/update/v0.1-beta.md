# v0.1-beta 更新日志

## v0.1.1

- 加入/proc目录显示进程状态的功能。
- 修复了每个 tty 所运行的 sh 不会因为执行了 `killall sh` 而全体瘫痪的 bug。

## v0.1.2

- TTY 首次、logout、异常退出后都经 login 启动。GUI 新终端也使用同一入口。
- users 新增 AutoLogin 即自动登录，要求唯一空密码 root，并且会校验调用者 root 身份与控制终端。
- IMG/ISO 默认 development profile，提供唯一空密码 root；普通 make install 不执行该 profile。可加入参数 `EXPORT_ACCOUNT_PROFILE=system` 导出普通账户模板。
- 完善了 DMA 模块，DMA API 必须持有设备资源域，MMIO 只允许已 claim 的设备，BAR 范围在 DMA 开启前探测并缓存。DMA 页使用外部映射，物理引用归资源域；正常 close 不会将仍可能被设备访问的页交回物理分配器。
- 新增 task、mm 等服务的故障恢复机制。
