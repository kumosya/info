# v0.1.4：guiw G01 对象接口与构建迁移

日期：2026-10-24。对应 `docs/prompt/v0.1.4-03-guiw-desktop-session-outline.md` 的 G01。GUI 软件包版本为 0.3.0，私有线协议版本为 3。

## 已交付

- `Connection` 持有服务连接及协商结果；Window 内部持有连接状态、窗口标识和事件订阅，不再暴露传入 service/window 的静态 API。
- Window 禁止复制、支持移动；对象共享内部连接状态，连接对象提前析构不会留下悬空引用。显式断开及服务重连会使旧窗口失效。
- Canvas 绑定窗口资源而非外层对象地址；移动窗口后仍有效，关闭或重新创建窗口后旧 Canvas 失效。
- Clipboard 改为连接对象上的实例客户端，能力协商从每次操作改为建立连接时一次执行。
- 公共容量、版本及服务名通过函数获取；固定批次传输结构移入不安装的 `src/wire.h`，Canvas 使用不透明内部状态。
- 自有公共头文件不含函数体、inline 或 constexpr；TextBitmap 构造函数和私有 SHA-256 实现也移入 `.cc`。
- terminal、calc、taskmgr、editor 迁移到新 API；保留原有 taskmgr 用户改动。
- console 显示交接迁移到 `os::Terminal::setGraphicalActive()`；移除 info 编译对 GUI SDK 的依赖。显示交接不是登录或锁屏接口。
- 发布脚本在项目内复制 SDK、先构建并导入新 GUI 库，再构建消费者，避免混用旧 ABI；未改动全局 SDK。

## 验证

- Linux/WSL 目标工具链构建及打包：libosgui-c++、guiw、guiw-app-tools（terminal/calc/taskmgr）、guiw-editor 全部通过。
- console 源码及 OS runtime 目标编译通过，console ELF 链接通过；动态依赖检查仅需要 `libos-c++.so`。
- `guiw/tests/client-lifecycle.sh` 使用 ASan/UBSan，通过连接提前销毁、窗口与连接移动、窗口重新打开、旧 Canvas 失效、重连代次、协议不匹配、异常事件响应、剪贴板长度/UTF-8 边界及句柄清理测试。
- 自有公共头文件检查通过；旧 static 调用点检查通过。库导出包含新对象接口，目标包不含私有 wire 头文件。
- 发布包版本均为 0.3.0，`guiw-app.zip` 包含 tools 和 editor 两个 `.inpk`；Settings 尚未实施，未加入本批包。
- 当前安装 SDK 缺少最新 TaskInfo.nice，验证使用项目内 `build/g01-sdk`，覆盖当前 OS 头文件及从源码构建的 OS 运行库。未覆盖用户现有镜像或 info/packages 中的 GUI 发布包。
- info 现有配置指纹已与用户工作区变更不一致，定向编译使用 `make -o build/config.mk` 固定已有生成配置，未重写用户配置。

## 产物与限制

发布目录为 `guiw/build/release/`：`libosgui-c++.inpk`、`guiw.inpk`、`guiw-app.zip`；构建用 SDK 副本为 `guiw/build/release-sdk/`。

本批属于接口基础设施交付，尚未执行 QEMU 启动和实际键鼠交互测试。两个演示窗口及原图形终端启动行为仍保留，登录、锁屏、壁纸、启动器、Settings 等属于 G02–G12，不能将本批包视为整个桌面计划已完成。

公共 API/ABI 和线协议已变化，库、服务端与应用必须配套更新；console 的新显示交接调用需要更新 OS 运行库。生命周期操作（连接建立/断开、窗口创建/关闭）由应用串行协调，不承诺与其他线程的这些操作并发安全。
